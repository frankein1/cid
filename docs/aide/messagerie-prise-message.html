Prendre un message pour un usager

Un appel arrive pour une personne que vous ne suivez pas ? Laissez-lui un message : il est transmis à la MDS qui la suit, qui peut le traiter et renseigner la réponse.

👤 Tous les agents connectés📍 Annuaire → « Prendre un message »⏱ 2 minutes

1Trouver l'usager

  1. Cherchez l'usager dans l'annuaire (Rechercher / créer un usager).
  2. Sur sa ligne, cliquez sur Prendre un message.

2Écrire le message

  1. Mode de contact demandé (facultatif) : courrier, accueil physique, téléphone ou courriel.
  2. Motifs : cochez un ou plusieurs motifs (logement, insertion, aide financière, adulte vulnérable, budget / CESF, autre).
  3. Indiquez la date de rappel, le destinataire, l'objet et le message, puis cliquez sur Envoyer.
Pour un même contact, envoyez un seul message : il sert aussi à compter les contacts.

3Suivre la réponse

  1. Le destinataire, agent de la MDS qui suit l'usager, ouvre le message et renseigne la prise de message : type de réponse, texte, et case Réponse effectuée.
  2. La date de réponse est enregistrée à la première validation de la case.

Bon à savoir

  • Vous ne voyez pas la fiche de cet usager : elle reste réservée à sa MDS. Votre message, lui, reste visible de la MDS qui le suit et de vous.
