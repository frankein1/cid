# Réunion IP et désignation du binôme — aide-mémoire

**Qui :** cadre de la MDS · **Fiche illustrée :** [ip-binome.html](../ip-binome.html)

1. Ouvrir l'IP → **Démarches et réunions** → **Réunion IP** : date, résultat, présents, compte rendu → Enregistrer.
2. **Binôme** : CID propose l'**équipe IP** d'abord, puis les moins chargés (+ PMI si enfant ≤ 5 ans ou situation particulière). Qui suit déjà la famille n'est pas proposé ; « Désigner quand même… » pour passer outre (tracé).
3. Choisir les deux professionnels → **Valider le binôme** → messages envoyés, IP **en évaluation**. Binôme modifiable ensuite.
