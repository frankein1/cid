# Décider une AFASE — aide-mémoire

**Qui :** cadre de la MDS (inspecteur si mesure ASE) · **Où :** Cadre → AFASE et CAP à traiter · **Fiche illustrée :** [afase-decider.html](../afase-decider.html)

1. **Cadre → AFASE et CAP à traiter** → **Décider** (échéance des 2 mois affichée ; réputées refusées en rouge).
2. Lire l'**aide à la décision** : reste à vivre, AFASE des 12 derniers mois, objet, aides sollicitées, référentiel.
3. Cocher **Accord / Refus / Ajournement** :
   - accord : motif, montant mensuel, durée ;
   - refus : code ; codes 3 et 7 → **précision pour le courrier** ;
   - ajournement : écrire ce qu'il faut compléter (15 jours).
4. Le **motif** texte est interne (absent du courrier).
5. **Enregistrer** (le bouton reprend la décision choisie).

- Sans décider : **Renvoyer au travailleur social sans décision**.
- Ajournée depuis plus de 15 jours : refus code 1 proposé.
