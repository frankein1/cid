# Évaluer une IP — aide-mémoire

**Qui :** binôme d'évaluation · **Fiche illustrée :** [ip-evaluer.html](../ip-evaluer.html)

- **Programmer une audition** (parents ou enfants) : date, durée, adultes convoqués (un courrier chacun), enfants (courrier à l'adulte qui les héberge), professionnels → **Programmer et préparer les convocations** (PDF dans les démarches, agenda).
- **Présences** : présent / absent / absence justifiée – report convenu. **Reconvoquer** à l'amiable ou en LRAR (n° demandé).
- **Autre démarche** : appel, VAD, courriel, partenaire… ; **Mettre à jour** pour noter le résultat d'une démarche prévue.
- **Rapport** → Rédiger / ouvrir : déroulé repris des démarches, rubriques, conclusion **par enfant** (danger / risque / pas de danger + types), préconisation → **Enregistrer le brouillon** ou **Soumettre pour la synthèse**.
