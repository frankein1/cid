# Organiser la MDS : fonctions, équipe IP, MDS de proximité — aide-mémoire

**Qui :** cadres de MDS ; super-administrateurs pour le type de MDS · **Fiche illustrée :** [mds-organisation.html](../mds-organisation.html)

1. **Type de MDS** : fiche de la MDS → Modifier → MDS de territoire ou de proximité ; pour une MDS de proximité, sa MDS de territoire de rattachement.
2. **Fonction** : Gestion des agents → modifier l'agent → Fonction (CODIR, cadre ou adjoint de proximité, autre). L'intitulé est proposé, corrigeable ; il est repris sous la signature.
3. **Équipe IP** : cocher la case sur la même page → proposé(e) en premier pour les binômes IP. Le cadre reste libre.
4. **CODIR** : accès automatique aux MDS de proximité rattachées (mention CODIR, géré depuis la MDS de territoire, sans gestion des comptes).
