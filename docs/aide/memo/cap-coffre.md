# Gérer le coffre de chèques service — aide-mémoire

**Qui :** régisseur de la MDS · **Où :** menu Coffre CAP · **Fiche illustrée :** [cap-coffre.html](../cap-coffre.html)

- **Réception** : Nouvelle réception (validité, bordereau) → saisie à la douchette par valeur → **Terminer la saisie** (bordereau PDF).
- **Incident** : ligne du chèque → **Signaler…** (perdu, volé, retourné) + commentaire.
- **Inventaire** : **Inventaire** → scanner tous les chèques présents → écarts par valeur → **Terminer l'inventaire** (procès-verbal PDF).
