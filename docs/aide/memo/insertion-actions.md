# Consulter les actions d'insertion — aide-mémoire

**Qui :** agents du module RSA · **Fiche illustrée :** [insertion-actions.html](../insertion-actions.html)

**Accompagnement → RSA – Insertion → Actions d'insertion** → filtres (texte, type, niveau, pôle, état) → ouvrir une action : périmètre, porteur, durée, public, destinataires de la prescription, pièces à joindre, comité de suivi technique. Étiquette « locale » = action d'une MDS. Une action arrêtée passe inactive (jamais supprimée).
