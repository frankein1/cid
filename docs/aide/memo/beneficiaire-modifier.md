# Modifier un bénéficiaire — aide-mémoire

**Qui :** tous les agents de la MDS · **Où :** fiche du bénéficiaire · **Fiche illustrée :** [beneficiaire-modifier.html](../beneficiaire-modifier.html)

1. Fiche → **Modifier**.
2. Corriger : **1. État civil** (dont nom de naissance) · **2. Coordonnées** · **3. Informations administratives** (NIR, n° CAF, n° France Travail, n° fiscal, référent social).
3. **Enregistrer les modifications** → message « Mise à jour effectuée ».

- La MDS de rattachement ne se change pas ici : **Transférer**.
