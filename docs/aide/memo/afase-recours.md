# Enregistrer un recours — aide-mémoire

**Qui :** cadre (ou inspecteur) · **Où :** fiche de l'AFASE refusée · **Fiche illustrée :** [afase-recours.html](../afase-recours.html)

1. AFASE refusée → **Recours de l'usager** : type (gracieux / contentieux), date → **Enregistrer un recours**.
2. Décision connue : issue (refus réformé / confirmé / désistement) + date → **Enregistrer l'issue**.
3. Refus réformé : **nouvelle AFASE** créée (reprise de la demande), à décider ; pas de délai de 2 mois ; courrier « suite à votre recours ».
4. Pièce facultative **Décision sur le recours** (nouvelle AFASE, ou AFASE refusée si confirmé).

- Le premier refus et son courrier ne changent pas.
- Statistiques des aides : section « Recours contre les refus d'AFASE ».
