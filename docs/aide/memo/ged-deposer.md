# Déposer et consulter un document — aide-mémoire

**Qui :** agents de la MDS · **Fiche illustrée :** [ged-deposer.html](../ged-deposer.html)

1. Fiche usager → **Document** : fichier, titre, type (date d'expiration), confidentialité (Public DITAS / MDS uniquement / Nominatif) → **Archiver**.
2. Pas de document médical dans CID : pli scellé au médecin du service.
3. Consulter : fiche usager → **Voir tout** → GED par catégorie → ouvrir → Télécharger / Modifier.
