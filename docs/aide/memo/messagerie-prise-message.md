# Prendre un message pour un usager — aide-mémoire

**Qui :** tous les agents connectés · **Où :** annuaire → **Prendre un message** · **Fiche illustrée :** [messagerie-prise-message.html](../messagerie-prise-message.html)

1. Chercher l'usager dans l'annuaire, puis **Prendre un message** sur sa ligne.
2. Remplir : **mode de contact** demandé (facultatif : courrier, accueil physique, téléphone, courriel) ; **motifs** (un ou plusieurs ; « Réaffectation » demande à la MDS d'origine de réaffecter l'usager) ; **date de rappel** ; destinataire ; objet ; message → **Envoyer**.
3. Le destinataire (agent de la MDS qui suit l'usager) renseigne la **prise de message** : type de réponse, texte, case **Réponse effectuée**. La date de réponse n'est enregistrée qu'une fois.

- Un seul message par contact : il sert aussi à compter les contacts.
- Vous ne voyez pas la fiche de l'usager si vous n'êtes pas de sa MDS ; votre message reste visible de vous, de ses destinataires et de sa MDS.

## Réaffectation (cadre de la MDS d'origine)

- Message avec le motif **Réaffectation** : seul le **cadre** de la MDS d'origine décide.
- **Accepter** : l'usager et les membres de son foyer cochés sont transférés ; la MDS demandeuse reçoit une réponse.
- **Refuser** : motif obligatoire, transmis dans la réponse. L'usager ne bouge pas.
- Demande close dans les deux cas, une seule décision possible.
