# Demander une AFASE — aide-mémoire

**Qui :** travailleur social · **Où :** fiche de l'usager → Aides financières · **Fiche illustrée :** [afase-demander.html](../afase-demander.html)

1. Fiche → **Aides financières** → **Nouvelle AFASE**.
2. **Contexte** : demandeur, lien avec l'enfant, **date de signature** (départ du délai de 2 mois), avis, qualité, CAF, situations pro ; cocher les **enfants concernés** (enfant à naître : case + date prévue).
3. **Demande** : montant mensuel, durée, **objet** (référentiel affiché), aides de droit commun sollicitées, **mesure ASE** éventuelle (→ inspecteur).
4. **Évaluation** : code de la demande, situation, analyse, justification, plan d'action, adhésion.
5. **Budget** : ressources, charges payées / non payées, dettes, personnes au foyer → reste à vivre. **Enregistrer la demande** (brouillon).
6. **Ajouter un document** pour chaque pièce : identités, livret de famille (ou attestation CAF/MSA), RIB au nom du destinataire, domicile < 3 mois, justificatif de l'objet.
7. **Instruire / Finaliser** → **Finaliser et transmettre au Cadre** → « Déposée au cadre ».

- Corriger avant dépôt : **Modifier la demande**.
- Encadrés de vigilance : informatifs, le cadre décide.
