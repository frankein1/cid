# Avis de l'inspecteur sur une IP — aide-mémoire

**Qui :** inspecteur enfance-famille · **Fiche illustrée :** [ip-inspecteur.html](../ip-inspecteur.html)

1. Message CID ou liste des IP (statut **Transmise à l'inspecteur**) → ouvrir le rapport.
2. **Votre avis** : D'accord (contresigner) / Autre suite (décision + motivation) / Complément d'évaluation (retour au binôme).
3. **Enregistrer mon avis** → accord ou autre suite : IP **clôturée**.
