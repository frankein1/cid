# Envoyer et lire un message — aide-mémoire

**Qui :** tous les agents · **Fiche illustrée :** [messagerie.html](../messagerie.html)

- **Pour un usager** : annuaire → **Prendre un message** (voir [la fiche dédiée](messagerie-prise-message.md)). Le bouton **Message** de la fiche ouvre le même formulaire.
- **Hors usager** : **Messagerie → Nouveau message**. Destinataire (+ copie), objet, motif, priorité, texte.
- **Joindre** : cocher des documents de la GED, ou ajouter des fichiers (classés dans la GED de l'usager) → **Envoyer**.
- **Lire** : compteur sur le menu Messagerie ; ouvrir → pièces jointes, lien vers le dossier → **Répondre**. Pour un message sur un usager, le destinataire renseigne aussi la prise de message.
- **Trier** : Tous / Non lus / Urgents ; onglet Envoyés.
