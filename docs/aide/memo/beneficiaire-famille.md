# Ajouter un membre de la famille — aide-mémoire

**Qui :** tous les agents de la MDS · **Où :** fiche du bénéficiaire · **Fiche illustrée :** [beneficiaire-famille.html](../beneficiaire-famille.html)

1. Fiche → **Ajouter un lien**.
2. **Type de lien** : Parent, Enfant, Conjoint, Placement, Tuteur, Tiers.
3. Personne connue : **Bénéficiaire cible** (3 lettres, choisir) — sinon **Ou créez un nouveau bénéficiaire** (civilité, nom, prénom, date de naissance).
4. Cocher **Vit au foyer** / **Responsable légal** si c'est le cas → **Créer le lien**.

- Lien enregistré dans les deux sens (enfant ↔ parent).
- Une personne créée ici reprend l'adresse et la MDS : corriger avec **Modifier** si elle vit ailleurs.
- **Vit au foyer** = nombre de personnes au foyer proposé dans l'AFASE.
