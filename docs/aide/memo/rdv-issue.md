# Noter l'issue d'un rendez-vous — aide-mémoire

**Qui :** agent du rendez-vous, cadre · **Fiche illustrée :** [rdv-issue.html](../rdv-issue.html)

**Planning → Calendrier** → cliquer le rendez-vous → issue (réalisé, absent, venu non reçu, annulé / reporté par l'usager ou la MDS, VAD usager absent) + 1er rendez-vous → **Enregistrer**. **Libérer le créneau** pour rendre une permanence disponible.
