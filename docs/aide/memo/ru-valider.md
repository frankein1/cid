# Valider l'évaluation RU (cadre) — aide-mémoire

**Qui :** cadres de MDS · **Fiche illustrée :** [ru-valider.html](../ru-valider.html)

1. Ouvrir la demande dans la liste (état **À valider par le cadre MDS**).
2. Relire l'évaluation, les rendez-vous et les courriers. Vous pouvez corriger le texte jusqu'au visa.
3. Section **3. Validation et signature du cadre** : **Valider et transmettre au SAS**.
4. CID enregistre vos initiales, la date et l'heure, puis envoie un message interne aux agents SAS habilités.

La validation est une signature de workflow (initiales, identité, heure), non une signature électronique qualifiée. Après le visa, l'évaluation est figée : le circuit ne prévoit pas de nouveau visa. Si une difficulté apparaît, prévenez le SAS avant de valider.
