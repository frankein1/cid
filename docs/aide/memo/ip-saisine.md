# Saisine du procureur — aide-mémoire

**Qui :** binôme, cadre, inspecteur · **Fiche illustrée :** [ip-saisine.html](../ip-saisine.html)

1. **Binôme** : cadre « Saisine du procureur » → motif (+ danger grave et imminent) → **Proposer au cadre**.
2. **Cadre** : **Demander à l'inspecteur** / **Urgence : saisir directement** / **Ne pas retenir** (commentaire).
3. **Inspecteur** : valide ou non.
4. Validée → **Imprimer le courrier de saisine** → après envoi : date, référence/mode → **Saisine envoyée**.
