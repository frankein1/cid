# Se connecter — aide-mémoire

**Qui :** tous les agents · **Fiche illustrée :** [connexion.html](../connexion.html)

1. Ouvrir CID dans le navigateur.
2. Saisir son **nom d'utilisateur** et son **mot de passe** → **Se connecter**.

**Mot de passe oublié**
1. Page de connexion → **Mot de passe oublié ?** → nom d'utilisateur → **Prévenir l'administration**.
2. L'administration communique un mot de passe provisoire : initiales en majuscules + date du jour (`AS01112026`).
3. À la connexion, CID impose d'en choisir un nouveau.

- Changer son mot de passe à tout moment : clic sur son nom (en haut à droite) → **Changer mon mot de passe**.
- Le menu dépend du profil (TS, cadre, CRIP…). Poste partagé : **Déconnexion**.
