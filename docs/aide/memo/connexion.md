# Se connecter — aide-mémoire

**Qui :** tous les agents · **Fiche illustrée :** [connexion.html](../connexion.html)

1. Ouvrir CID dans le navigateur.
2. Saisir son **nom d'utilisateur** et son **mot de passe** → **Se connecter**.

- Mot de passe oublié : s'adresser au gestionnaire des accès (le lien de la page n'est pas encore actif).
- Le menu dépend du profil (TS, cadre, CRIP…).
- Poste partagé : **Déconnexion**, en haut à droite.
