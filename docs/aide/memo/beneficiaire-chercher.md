# Chercher un bénéficiaire — aide-mémoire

**Qui :** tous les agents de la MDS · **Où :** Bénéficiaires → Liste complète · **Fiche illustrée :** [beneficiaire-chercher.html](../beneficiaire-chercher.html)

1. **Bénéficiaires → Liste complète**.
2. Saisir le **nom** ; affiner si besoin : prénom, date de naissance, NIR / n° CAF / n° France Travail / téléphone.
3. **Rechercher** (ou `Entrée`), puis cliquer sur la ligne de la personne.

- Aucun résultat : vérifier l'orthographe, alléger les critères, **puis seulement** créer la personne.
- Le **code interne** (ex. `FAM9-CEL`) est le repère le plus sûr entre collègues.
- Usager d'une autre MDS : fiche consultable (identité, coordonnées, référent, famille), aides et documents réservés à sa MDS.
