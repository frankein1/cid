# Chercher un usager — aide-mémoire

**Qui :** tous les agents · **Où :** menu *Rechercher / créer un usager* (annuaire) · **Fiche illustrée :** [beneficiaire-chercher.html](../beneficiaire-chercher.html)

1. Ouvrir **Rechercher / créer un usager**.
2. Renseigner **un** élément (code usager, n° CAF ou téléphone), ou **deux** au choix (nom, prénom, date de naissance, adresse) → **Chercher**.
3. Sur la ligne de l'usager :
   - **Prendre un message** : ouvert à tous les agents, quelle que soit la MDS.
   - **Ouvrir la fiche** et **Transférer** : agents de la MDS de rattachement seulement.
4. Aucun résultat : vérifier l'orthographe, alléger les critères, **puis seulement** **Créer cet usager**.

- Le **code interne** (ex. `FAM9-CEL`) est le repère le plus sûr entre collègues.
- Dates proches (Frederik / Frédéric) : vérifier la date de naissance.
- Chaque recherche est inscrite au journal d'activité.
