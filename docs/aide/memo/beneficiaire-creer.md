# Créer un bénéficiaire — aide-mémoire

**Qui :** tous les agents de la MDS · **Où :** Bénéficiaires · **Fiche illustrée :** [beneficiaire-creer.html](../beneficiaire-creer.html)

1. **Passer par l'annuaire** : menu *Rechercher / créer un usager*. Cherchez par code usager, n° CAF, téléphone, ou deux éléments (nom, prénom, date de naissance, adresse).
2. **Usager trouvé** : ouvrez sa fiche, ou **Prendre un message** pour lui laisser un message à rappeler.
3. **Usager non trouvé** : **Créer cet usager**. Le formulaire est prérempli avec ce que vous avez cherché.
4. Obligatoire (*) : civilité, nom, prénom, date de naissance, adresse, code postal, ville, MDS de rattachement.
   - Date : `14/03/1991` ou `140391` ; commune proposée d'après le code postal ; référent facultatif.
5. Cochez **« Je confirme que l'usager n'existe pas dans l'annuaire »**, puis **Créer l'usager**. La fiche s'ouvre avec son **code interne**.
   - Une recherche ne permet qu'une création. Pour un autre usager, recherchez-le à nouveau.

- Numéros (NIR, CAF, France Travail…) : ensuite, avec **Modifier**.
- Enfants, conjoint : depuis la fiche, **Ajouter un lien**.
