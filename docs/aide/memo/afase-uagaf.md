# Contrôler et payer une AFASE — aide-mémoire

**Qui :** UAGAF · **Où :** menu UAGAF (AFASE) · **Fiche illustrée :** [afase-uagaf.html](../afase-uagaf.html)

1. **UAGAF (AFASE)** → **Ouvrir** le dossier transmis.
2. Conforme : saisir la demande de paiement dans le logiciel comptable, puis dans CID **date** (+ n° d'enregistrement facultatif) → **Paiement demandé**.
3. Non conforme : **motif** → **Renvoyer à la MDS** (cadre prévenu).
4. Paiement effectué : **date**, **montant payé** (vide = montant accordé ; partiel possible) → **Payé : clôturer le dossier** (MDS prévenue).
