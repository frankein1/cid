# Importer et exporter les actions (CSV) — aide-mémoire

**Qui :** pôles insertion (cadres de MDS : actions locales) · **Fiche illustrée :** [insertion-import.html](../insertion-import.html)

1. **Importer (CSV)** → télécharger le **fichier modèle** (ou l'export) → une action par ligne → CSV, séparateur « ; ».
2. Déposer → **Analyser le fichier** : créations / mises à jour / erreurs, rien n'est enregistré.
3. **Enregistrer** : lignes en erreur ignorées (à corriger puis réimporter). Rien n'est supprimé (actif = non pour retirer).
4. **Exporter (CSV)** : même format, pour des mises à jour en masse.
